Sincronización en la nube

Para usar tus datos en varios dispositivos a la vez, necesitas una base de datos Firebase Realtime Database gratuita a tu nombre (Google), ya que esta app no tiene servidor propio. Es gratis y tarda unos minutos: crea un proyecto en console.firebase.google.com, activa "Realtime Database" en modo de prueba, y copia aquí la URL que te da (algo como "https://tu-proyecto-default-rtdb.firebaseio.com").

Usa la misma URL y el mismo código en cada dispositivo que quieras mantener sincronizado. Cualquiera que sepa este código y esta URL podría leer o cambiar tus datos, así que usa algo que no sea fácil de adivinar.
